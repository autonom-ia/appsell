# Operating Model

## Papéis

- Planner: investiga e planeja.
- Implementer: implementa escopo aprovado.
- Reviewer: revisa criticamente.
- Security Reviewer: revisa riscos de segurança.
- Memory Curator: atualiza memória.
- Release Checker: valida deploy e rollback.

## Etapas

1. Issue.
2. Investigação.
3. Mapa técnico ponta a ponta.
4. Plano e owner de orquestração.
5. Branch.
6. Implementação.
7. Testes focados.
8. PR.
9. Project update.
10. Reviewers concluem e atingem a barreira de junção.
11. Findings deduplicados e uma onda consolidada de correção.
12. Re-review do delta, no máximo duas ondas.
13. Suíte completa e uma única revisão ampla final.
14. Aprovação.
15. Merge.
16. Deploy/rollback plan.

O protocolo executável está em `REVIEW_CONVERGENCE.md`.
