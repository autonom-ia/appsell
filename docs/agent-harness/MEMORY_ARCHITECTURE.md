# MEMORY_ARCHITECTURE.md

## Objetivo

Definir a camada de memória do Autonom.ia Agent Harness.

## Camadas

- MEMORY_CORE.md: regras permanentes.
- MEMORY_PROJECT.md: contexto do projeto.
- MEMORY_USER.md: como Rodrigo prefere trabalhar.
- MEMORY_SESSION.md: estado da tarefa atual.
- MEMORY_LEARNINGS.md: aprendizados com evidência.
- MEMORY_DECISIONS.md: decisões explícitas.
- MEMORY_COMPACTION.md: regras de compactação.

## Regra

Memória não é tudo igual. Informação permanente, informação do projeto, estado da sessão e aprendizado devem ficar separados.

## Aprendizados

Aprendizados entram como candidatos e precisam de evidência.

Formato:

```md
## Aprendizado 001

Data:
Origem:
Evidência:
Aprendizado:
Confiança:
Revisado por Rodrigo:
```
