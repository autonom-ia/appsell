# SKILLS_POLICY.md

## Objetivo

Definir como skills são criadas, avaliadas e usadas.

## Regra

Skills devem ser portáveis entre ferramentas sempre que possível.

## Estrutura recomendada

Cada skill deve definir:

- nome;
- objetivo;
- quando usar;
- quando não usar;
- inputs;
- outputs esperados;
- ferramentas permitidas;
- risco;
- validação;
- exemplos.

## Skills iniciais

- systematic-debugging
- spec-writing
- issue-shaping
- project-update
- pr-review
- memory-compaction
- tool-design
- rollback-planning
- security-review
- harness-install-or-update

## Superpowers

O framework `obra/superpowers` pode ser usado como inspiração para skills e workflows, mas deve ser adaptado para as regras da Autonom.ia.
