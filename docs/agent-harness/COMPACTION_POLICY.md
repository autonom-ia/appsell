# COMPACTION_POLICY.md

## Objetivo

Evitar perda de contexto em sessões longas.

## Nunca perder

- objetivo da tarefa;
- Issue;
- branch;
- PR;
- decisões do Rodrigo;
- arquivos alterados;
- comandos executados;
- resultados de validação;
- riscos;
- rollback;
- Project status;
- próxima ação.

## Pode descartar

- logs repetidos;
- outputs longos já resumidos;
- conversa social;
- hipóteses descartadas;
- tentativas abandonadas.

## Antes de compactar

Atualizar:

- docs/memory/MEMORY_SESSION.md
- docs/PROGRESS.md

## Depois de compactar

Validar que continuam claros:

- objetivo;
- estado atual;
- bloqueios;
- próxima ação;
- Project status.
