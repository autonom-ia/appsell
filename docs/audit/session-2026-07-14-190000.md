# Audit trail — VPS preview artifact pipeline

- Issue: https://github.com/autonom-ia/appsell/issues/66
- Branch: `infra/66-vps-preview`
- Base: PR #67 head `b7c9a21bc38b151724ec6c7415bb8caf3b6faa9c`
- Product: Autonom.ia Sell
- Environment: Local/CI and additive VPS preview only

## Outcome

- no Docker build on the Mac or VPS;
- Autonom.ia Sell, Domain, Alpine, PostgreSQL, Redis and Foundation build as
  GitHub-hosted Docker TAR artifacts;
- Auth PR validation is secret-free; trusted Auth publisher is isolated in
  autonomia-identity-auth Issue #27;
- GitHub Artifact Attestations were proven unavailable for user-owned private
  repositories by real CI; artifacts are instead verified fail-closed against
  exact repo, workflow, branch, run, source SHA, GitHub-hosted jobs, GitHub API
  SHA-256 digest, embedded provenance and subject checksum before upload;
- VPS loads exactly one expected RepoTag per TAR after exact checksum/tree checks;
  Compose and E2E enforce `pull_policy: never`/`--pull never` for every service;
- Compose publishes only loopback ports 13200/13217 and creates dedicated
  PostgreSQL, Redis, network, volumes and containers;
- runtime cap peak is below 4.8 GiB and preflight requires 12 GiB available,
  eight logical CPUs, low load and 30 GiB Docker disk headroom;
- the activation orchestrator pins the Compose project name, sanitizes Compose
  control variables and rolls back immediately on load, start, E2E or
  existing-state comparison failure;
- before the first image load, the pipeline enforces amd64, Compose feature
  support, utility availability, free ports, per-TAR/total size ceilings and
  30 GiB plus three times the TAR bundle size as disk headroom;
- persistent systemd timer survives reboot, bounds teardown with timeout plus
  forced kill, retries failures, and removes the
  exact Issue #66 resources, images, secrets, TARs and run root after 48 hours;
- no Financial, Neuro.ai, GitHub OAuth, AWS production credential or customer
  database is connected to this preview.
