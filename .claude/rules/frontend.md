# Frontend Rules

- Preservar layout e identidade visual existentes.
- Não inventar assets, logos, cores ou dados de negócio.
- Preferir componentes pequenos e legíveis.
- Validar estados vazios, loading e erro.
- Não misturar refactor visual com bugfix funcional.
